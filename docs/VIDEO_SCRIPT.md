### Recording tips

1. Use **Load seeded demo** so the story is reliable.
2. Prefer **Live** mode if `OPENAI_API_KEY` is set (shows green Live badge) — otherwise say “seeded demo path” once.
3. Zoom browser to ~110% so stage labels read clearly on phone playback.
4. Click the Thunder logo anytime to reset to stage 1 between takes.
