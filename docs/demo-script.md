# Demo script (≤2 minutes)

## Setup

1. Open the deployed demo (or `npm run dev`).
2. Confirm seeded content is loaded (or click **Load seeded demo**).
3. Optional: mention Live vs Demo/fallback badge.

## Narration

**0:00–0:20 — Problem**  
Creators guess how a post will land. Comments already contain the audience map — unused.

**0:20–0:40 — Run**  
Click **Run Audience Test**. Point at the multi-agent loading orchestra: Research → Simulation → Critic → Deterministic scoring → Content Strategy.

**0:40–1:00 — Audience Twin**  
Three segments with evidence IDs. Expand comments. Credibility beat.

**1:00–1:20 — Reaction Lab**  
Show disagreement strip. Beginners vs builders vs skeptics want different things.

**1:20–1:40 — Diagnostics**  
Five scores + “How calculated”. Guardrails catch exaggeration / unsupported claims.

**1:40–1:55 — Carousel + Before/After**  
Five slides. Then before/after table — the memorable moment.

**1:55–2:00 — Close**  
“Test your post before your audience does.” Not a view oracle — a grounded rehearsal.
