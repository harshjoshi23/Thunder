# Demo script (~2 minutes)

1. Open Thunder → badge empty until a run completes.
2. Click **Load seeded demo** (consistency / hustle weak draft + 15 comments).
3. Optional: paste a source URL and **Fetch source** (needs Firecrawl; otherwise labeled recovery).
4. Click **Run Audience Test**.
5. Call out the mode badge:
   - **Live** — fal keys present and pipeline succeeded
   - **Seeded demo** — intentional demo path
   - **Recovery fallback** — services missing/failed (never silent fake-live)
6. Stage 2 Audience Twin → three segments with evidence IDs (C01…).
7. Stage 3 Reaction Lab → disagreement across segments.
8. Stage 4 Diagnostics → deterministic 0–100 scores + formula disclosure.
9. Stage 5 Carousel → hook + 5 slides; **Generate Cover**, **Generate Voiceover**, **Approve & Send to n8n**.
10. Stage 6 Before/After → score lift after strategy.
11. Point at Technical credibility panel (models + executionTrace).

## Talking line

“Thunder is scenario testing — an audience twin and multi-agent jury that rehearses how segments will react, then rewrites the carousel with evidence-linked changes. It does not claim to predict virality.”
